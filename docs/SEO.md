# SEO and discovery

Everything here is implemented once, in `src/layouts/Base.astro`, `src/lib/seo.ts`, and the endpoints in `src/pages/`. Pages pass data; they do not write head tags. `tests/build/seo.test.ts` enforces the contract.

## Per-page contract

| Item                 | Rule                                                                                                    | Source                                             |
| -------------------- | ------------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| `<title>`            | `Title · Jewei Mak` when ≤ 65 chars, else the title alone. Home: `site.homeTitle`. Unique.              | `documentTitle()`                                  |
| Meta description     | 40–200 chars (aim 120–160). Unique.                                                                     | page data, post `description`, topic `description` |
| Canonical            | Absolute, trailing slash, equals `og:url`. None on 404.                                                 | `Base.astro`                                       |
| Robots               | `index, follow, max-image-preview:large`; 404 is `noindex`                                              | `Base.astro`                                       |
| H1                   | Exactly one per page                                                                                    | tests                                              |
| Open Graph / Twitter | title, description, type, url, image (+width, height, alt), `summary_large_image`                       | `Base.astro`                                       |
| Social image         | Custom `image` cropped to the largest true 1.91:1 size, or a generated 1200×630 card at `/og/<key>.png` | `src/lib/og.ts`                                    |
| Articles             | `article:published_time`, `article:modified_time`, `article:author`, `article:tag`                      | `[slug].astro`                                     |
| Markdown alternate   | `<link rel="alternate" type="text/markdown">` to `<path>/index.md`                                      | `Base.astro`                                       |
| `rel="me"`           | GitHub and X                                                                                            | `Base.astro`                                       |

## Structured data

One JSON-LD `@graph` per page. Every page includes `WebSite` and `Person` (stable `@id`s: `https://jewei.net/#website`, `https://jewei.net/#person`). Page-specific nodes:

| Page             | Nodes                                                                                                               |
| ---------------- | ------------------------------------------------------------------------------------------------------------------- |
| Home             | `ProfilePage`                                                                                                       |
| Article          | `BlogPosting` (headline, dates, wordCount, timeRequired, keywords, image, author, isPartOf Blog) + `BreadcrumbList` |
| Writing          | `Blog` with every `BlogPosting` + `BreadcrumbList`                                                                  |
| Topic            | `CollectionPage` with `ItemList` + `BreadcrumbList`                                                                 |
| Projects         | `CollectionPage` with `ItemList` of `SoftwareApplication` / `SoftwareSourceCode`                                    |
| About, Résumé    | `ProfilePage` with the full `Person`                                                                                |
| Contact, Privacy | `ContactPage` / `WebPage`                                                                                           |

## Site files

| File                 | Notes                                                                 |
| -------------------- | --------------------------------------------------------------------- |
| `/sitemap-index.xml` | `@astrojs/sitemap`; `lastmod` from post dates; 404 excluded           |
| `/rss.xml`           | All published posts with categories, `atom:link rel="self"`, language |
| `/robots.txt`        | Allow all, sitemap link. Generated by `src/pages/robots.txt.ts`.      |
| `/llms.txt`          | Agent guide generated from pages, posts, topics, and projects         |
| `/<path>/index.md`   | Markdown copy of every page (`scripts/build-markdown.ts`)             |
| `/site.webmanifest`  | Generated from `site.config.ts`                                       |

The Cloudflare middleware serves the Markdown copy for `Accept: text/markdown` on the normal URL, adds `Link` headers for the alternate and `llms.txt`, and sets `Vary: Accept`.

## Performance budget

Static HTML with inlined CSS, three self-hosted variable fonts (two preloaded), WebP images with `srcset`, no framework JS, under 8 KB of site JS, and Speculation Rules prefetch on hover. Target: Lighthouse 95+ in every category on mobile. Last measured: 99 / 100 / 100 / 100 on seven routes, CLS 0.

## When you add a page

1. Add its title, description, and card text to `src/data/pages.ts`.
2. Render through `Base.astro` with `image={ogPath('<key>')}` and a schema node.
3. Run `vp run test:build`. The tests check uniqueness, lengths, canonical, social image size, JSON-LD, sitemap, links, and the Markdown copy.
