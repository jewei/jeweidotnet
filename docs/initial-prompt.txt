Create a playful, minimal blog design for jewei.net.

The site is currently built with Astro.js, so the design should be suitable for a modern static blog or personal website. The overall feel should be clean, lightweight, expressive, and slightly whimsical without becoming cluttered.

Design goals:
- Minimal layout with playful visual details
- Fast, readable, and content-focused blog experience
- Friendly personal-site personality
- Suitable for a developer, maker, or creative writer
- Easy to translate into Astro components

Style direction:
- Clean typography with strong readability
- Generous spacing and simple page structure
- Soft colors with one or two playful accent colors
- Subtle rounded corners
- Light illustrations, doodles, icons, or abstract shapes used sparingly
- Avoid heavy gradients, overly corporate styling, or complex animations

Pages to design:
1. Homepage
   - Short personal intro or tagline
   - Featured or latest blog posts
   - Simple navigation
   - Optional playful visual element near the hero section

2. Blog index page
   - List of posts with title, date, short excerpt, and tags
   - Minimal card or list-based layout
   - Clear visual hierarchy

3. Blog post page
   - Excellent reading experience
   - Large readable title
   - Date, tags, and optional reading time
   - Clean article typography
   - Code block styling suitable for technical posts
   - Previous/next post navigation

4. About page
   - Short personal bio section
   - Links to social profiles or projects
   - Friendly, informal tone

Core UI elements:
- Header with simple navigation: Home, Blog, About
- Footer with copyright, RSS, and social links
- Blog post cards or list items
- Tag pills
- Code blocks
- Callout/note boxes
- Light and dark mode support if possible

Visual personality:
The design should feel like a personal corner of the internet: calm, clever, approachable, and a little fun. Think “minimal blog with tiny moments of delight,” not a full cartoon-style website.

Output requirements:
- Provide a polished visual design concept
- Include layout suggestions for desktop and mobile
- Use semantic sections that can be implemented in Astro.js
- Keep the design simple enough to build without a large UI framework
